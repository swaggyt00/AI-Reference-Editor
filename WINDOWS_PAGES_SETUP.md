# GitHub Pages + бесплатный локальный монтаж на Windows

## Что где выполняется

- Публичный сайт: https://swaggyt00.github.io/AI-Reference-Editor/ (HTML/JS, GitHub Pages).
- Локальный монтажный API: http://127.0.0.1:8000 (FastAPI на **этом же** Windows-ПК).
- Python + FFmpeg монтируют видео локально. Видео, проекты, результаты не попадают в GitHub.
- Codex и платный облачный сервер НЕ нужны для запуска каждого монтажа.
- Chrome может спросить разрешение **Local network / Loopback network access**. Разрешайте **только** на доверенном сайте.

## Шаг 1. Один раз включите Pages

GitHub -> репозиторий `swaggyt00/AI-Reference-Editor` -> Settings -> Pages.
В **Build and deployment** выберите **Deploy from a branch**, branch `main`, folder `/docs`, Save.
Когда публикация закончится, адрес будет https://swaggyt00.github.io/AI-Reference-Editor/.
Это нужно сделать один раз в настройках GitHub: создание файлов /docs само по себе не гарантирует публикацию.

## Шаг 2. Установите необходимые программы на Windows (один раз)

Откройте «Терминал Windows» (PowerShell) и установите, если их ещё нет:

```powershell
winget install -e --id Python.Python.3.11
winget install -e --id Gyan.FFmpeg
```

После установки **закройте и заново откройте терминал**: иначе PATH может не обновиться.
Команды проверки: `py -3 --version`, `ffmpeg -version` и `ffprobe -version`.

## Шаг 3. Установите движок

На GitHub выберите **Code -> Download ZIP**, распакуйте архив в удобную постоянную папку,
например `C:\AI-Reference-Editor`. Нельзя запускать CMD из нераспакованного ZIP.

Дважды щёлкните `start-editor.cmd`. При первом запуске он создаст `.venv` и установит Python-зависимости.
Если Windows предупредит о запуске скачанного скрипта, изучите его содержимое и подтвердите только если доверяете коду.

**Оставьте окно CMD открытым**, пока монтируете. Сервер слушает только `127.0.0.1:8000`.

## Шаг 4. Сайт + локальный компьютер

1. Откройте GitHub Pages в Chrome **на этом же ПК**.
2. Нажмите **«Подключить ПК»**. Если появится запрос доступа к локальной сети / устройствам, разрешите.
3. Дождитесь «Движок подключён».
4. Загрузите референс и исходники, запускайте монтаж, скачивайте MP4.
5. Все результаты сохраняются также на диске в `output\web\`.

Если выдаёт «Движок недоступен», проверьте `http://127.0.0.1:8000/api/health` в **том же ПК**.
Ожидается JSON с `"ready":true`. Если нет — смотрите окно CMD.
Если health OK, но сайт не подключается, проверьте разрешение локальной сети Chrome
(замок/ползунки слева от адреса -> Site settings -> Local network access / Loopback network)
и перезагрузите страницу.

## Ограничения

- GitHub Pages НЕ является вычислительным сервером и не работает при выключенном ПК.
- Другие устройства не подключатся к вашему PC-серверу: интерфейс на Pages будет виден, но API расположен на `127.0.0.1` каждого устройства.
- Сейчас это прототип Reference Clone, а не полноценный senior AI-монтажёр:
  анализирует жёсткие склейки, чёрные боковые маски, создаёт монтаж. Большинство сложных эффектов и смысловой подбор кадров автоматически ещё не работают.
- Не используйте опцию «Разрешить любой доступ» или `--host 0.0.0.0`. Сервер специально не выставлен наружу.
- Сайт публичен, но это не делает ваши видео публичными. Не публикуйте файлы из `output`.
