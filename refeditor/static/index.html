    Задание на монтаж

    В Reference Clone свободное описание сохраняется как заметка; в Smart Reels Gemini учитывает вашу задачу при выборе лучших моментов.

    Как работает текстовое задание

    Пока это не свободное AI-управление. Исполняются только отдельные строки команд:

    звук: нет / референс / исходник
    режим: fit / native
    длительность: 15

    В каждой строке укажите одно значение. Команды имеют приоритет над настройками ниже. Остальной текст сохраняется для редактора и не исполняется автоматически.

    Только в Reference Clone с включённым Gemini. Remotion устанавливается отдельно через setup-motion.cmd. Добавляются только уверенно распознанные слои, не случайные шаблоны. Оригинальные B-roll и графические ассеты нужно предоставить отдельно.

    В Reference Clone Gemini анализирует сцены до 60 секунд, до 3 исходников. В Smart Reels анализируется один ролик до 30 минут. Сжатая копия со звуком передаётся Google только с вашего согласия. Возможны ограничения бесплатной квоты. Это не полноценный VFX-редактор.

    Fit меняет скорость исходников под длину сцен референса.

    Дополнительные настройки

    Обрезка конца видео; не удлиняет референс.

    Работает только при наличии общей звуковой дорожки.

    Используйте звук, на который у вас есть разрешение. Дорожка первого исходника берётся с начала; автоматического звукового монтажа нет.

    Файлы обрабатываются на сервере этого приложения.

    Возможности этой версии

    Reference Clone: измеряет склейки, чёрные/белые боковые панели и яркие вспышки. Gemini помогает выбрать подходящие исходники, но сложные VFX по-прежнему не копируются автоматически.

    Smart Reels (бета): Gemini выбирает интересные фрагменты длинного видео, FFmpeg собирает вертикальный ролик с сохранением речи и приглушённой фоновой музыкой. Выбор моментов и центрирование кадра требуют проверки.
